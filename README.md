# todo-list-app
A feature-rich To-Do List application built with HTML, CSS, and JavaScript featuring task management, search, dark mode, and local storage persistence.
## Features

- Add new tasks
- Delete tasks
- Edit tasks (double-click)
- Mark tasks as completed
- Search tasks
- Dark mode toggle
- Task statistics
- Local storage support
