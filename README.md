# 📝 To-Do List App

A modern and feature-rich To-Do List web application built using **HTML, CSS, and JavaScript**. This application helps users manage daily tasks efficiently with features such as task creation, editing, searching, completion tracking, dark mode, and local storage persistence.

## 🚀 Live Demo

🔗 https://syedabsar99.github.io/todo-list-app/

## 📸 Screenshot

![To-Do List App](images/screenshot.png)

## ✨ Features

* Add new tasks
* Edit tasks using double-click
* Delete tasks
* Mark tasks as completed
* Search tasks instantly
* Dark mode toggle
* Task statistics tracking
* Local storage support
* Responsive and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
